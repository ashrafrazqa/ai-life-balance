# AI Life Balance V10.2.7 — AI Performance Update

Fokus: mengurangi latency AI tanpa mengubah UI utama.

## Perubahan
- Worker menambahkan `thinkingConfig.thinkingLevel` untuk Gemini 3.6 Flash.
- Default tugas sederhana: `minimal` untuk latency lebih rendah.
- Request dengan gambar atau `systemInstruction` menggunakan `low` untuk menjaga kualitas analisis/chat.
- Jika request sudah membawa `thinkingConfig`, konfigurasi tersebut dipertahankan.
- Worker menambahkan `X-AI-Latency-Ms` dan `Server-Timing` agar waktu Gemini dapat diukur dari browser.
- `app.js` mencatat total waktu request dan latency Gemini di Console.
- Duplikasi `callGeminiAPI()` awal dihapus; hanya satu implementasi aktif yang dipertahankan.
- Service Worker cache dinaikkan ke V10.2.7.

## Tidak diubah
- UI V10.2.6.
- API key tetap server-side di Cloudflare Worker.
- Tidak ada perubahan pada rumus Energy Balance atau Balance Score.

## Cara test
1. Ganti folder `public` dengan versi ini untuk Live Server.
2. Buka DevTools → Console.
3. Jalankan beberapa fitur AI.
4. Cari log `[AI Performance] total=...ms gemini=...ms`.
5. Bandingkan Starting Point, Manual Scan, Activity, Coach, Meal Plan, dan Photo Scan.

## Catatan
Latency nyata tetap bergantung pada jaringan, beban layanan Gemini, ukuran gambar, dan quota. Perubahan `thinkingLevel` ditujukan untuk mengurangi latency pada tugas sederhana.
